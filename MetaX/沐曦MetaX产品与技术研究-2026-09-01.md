# 沐曦（MetaX）公开 AI 芯片与 GPU 产品研究

> 截止日：2026-09-01（中国标准时间）  
> 访问日期：2026-09-01  
> 研究范围：沐曦 MetaX 官方中文/英文官网、官方开发者文档，以及上海证券交易所披露的公司招股书。  
> 证据原则：官网产品目录证明“当前公开列出”；官网里程碑和新闻证明公司公开叙述；招股书属于监管披露；开发者文档证明软件支持或兼容标识。它们都不自动等于独立性能测试、持续量产、客户采购或公有云可用。

## 结论先行

沐曦截至 2026-09-01 在官网公开列出四条 GPU 产品线：

| 产品线 | 当前公开型号 | 公开定位 |
|---|---|---|
| 曦思 N 系列 | N100、N260、N300 | 智算推理、大模型推理 |
| 曦云 C 系列 | C500、C550、C500X、C588、C600 | 通用 GPU，训练、推理、通用计算、AI for Science |
| 曦彩 G 系列 | G100 | 图形渲染及图形/AI 统一场景 |
| 曦索 X 系列 | X206、X301、X302 | 科学智能、科学计算及 AI for Science |

已核验的产品形态并不只有芯片：沐曦把 GPU 芯片交给晶圆厂和封装测试厂生产，再由板卡厂商集成到 PCIe 板卡或 OAM 模组；官网还列出服务器、工作站、超节点和液冷整机柜。招股书明确说这些是不同交付层级，不能把“某型号 GPU”“某台服务器”“某个超节点”当成同一个芯片 SKU。

目前最清晰的状态判断如下：

- N100：首款推理 GPU，2022-01 交付流片、2022-08 回片并完成测试、2023-04 正式量产；监管披露称 2023 年底停产。
- C500：首款训推一体 GPU。官网里程碑写 2023-12“量产出货”，招股书写 2024-02“正式量产”，两者应并列记录；2024-11 招股书披露受美国禁令影响，无法继续向代工厂下达 C500 生产订单。
- C550：当前公开的主力 OAM 训推产品，64GB HBM2e、450W、8 卡全互连、官方页面给出 896GB/s；首次正式发布日、持续量产和客户部署规模未在本次核验的一手资料中确认。
- C500X：C500 家族的光互连板卡形态，64GB、350W，支持 16–64 卡 Scale-up；官网公开了对应光链超节点，但芯片流片、量产和客户部署日期未确认。
- C588：当前公开的 128GB OAM 旗舰，850W、8 卡全互连、896GB/s；招股书（签署时）仍写“在研”，官网后来已将其列入当前产品目录，但正式量产/出货日期未确认。
- C600：国产供应链新一代 OAM GPU。2024-10 流片，官网英文里程碑记录 2025-07 Bring Up，官网中文里程碑和新闻记录 2025-07 成功发布；当前页面给出 1000W、OAM2.0、最高 128 卡超节点，但容量、带宽、量产/客户部署日期未确认。
- N260、N300、G100、X206、X301、X302：官网已有产品页或当前目录条目；其中招股书曾把 N300 标为“在研”，G 系列在招股书签署时完成 GPU IP 设计和验证。其余型号的公开页面没有给出足够的流片、量产、出货或客户部署日期，不能据此推断商业成熟度。

没有在已核验的一手资料中发现一个被沐曦单独命名为“NPU”的产品家族。官网和招股书将这些产品统一称为 GPU、通用 GPU、智算推理 GPU、图形渲染 GPU 或科学智能 GPU；因此本文不把 GPU 的张量单元误写成独立 NPU。

### 1.2 层级边界

| 层级 | 本研究中的定义 | 已核验例子 |
|---|---|---|
| 芯片 | 经过流片、封装测试的 GPU 芯片设计/产品 | N100、C500、C600 等；招股书直接使用“GPU 芯片” |
| 板卡 | 芯片、HBM、供电、散热和 PCIe 等组成的可插拔卡 | N100 70W 半高半长 PCIe；C500 350W PCIe；C500X 定制高度 PCIe |
| 模组 | OAM 等扣卡形态，插入服务器基板 | C550、C588、C600，以及 X206/X302 OAM 服务器页面 |
| 服务器 | 集成多个板卡/模组、CPU、内存和互连的整机 | C500 服务器最高 16 卡；C550/C588/C600 服务器单机 8 模组 |
| 工作站 | 面向本地开发、设计或推理的整机 | N260 工作站；官网未列出完整规格 |
| 超节点 | 多服务器/多模组组成的 Scale-up 系统 | C500X 光链、C550 3D Mesh、Shanghai Cube |
| 整机柜 | 机柜级供电、散热、交换与计算交付 | C550 Shanghai Cube，47U、128 卡液冷布局 |
| 云服务 | 面向用户按服务提供的公有云/云端实例 | 本次核验未确认沐曦自营公有云产品或官方云 SKU |

招股书对交付链的原文逻辑是：沐曦负责 GPU 芯片设计，晶圆制造厂和封装测试厂完成芯片生产，板卡厂商完成芯片与板卡集成；沐曦也可向客户交付板卡/模组、服务器、一体机/工作站以及智算集群。该层级划分是本文后续状态判断的基础。

来源标题：沐曦集成电路（上海）股份有限公司《招股说明书》；披露日期：2025-10-24；访问日期：2026-09-01；[直接 PDF](https://static.sse.com.cn/stock/disclosure/announcement/c/202510/002078_20251024_OAW7.pdf)，产品层级见 PDF 印刷页 128。

### 4.1 关于“主力”和“上一代”的谨慎判断

- “主力”只有在公司自己明确使用时才使用。沐曦 2026-01-29 的官方新闻称 C500/C550 是“主力训推一体 GPU 产品”，因此可把 C500/C550 标为公司新闻口径的主力；不能据此推出销售额或市场份额。
- C500 是首款训推一体 GPU，也是已披露产业化最完整的 C 系列起点；C550、C588、C600 是后续更高规格或新供应链方向，但没有完整公开的逐代芯片微架构差异表。
- N100 是明确停产的上一代推理产品；N260 是当前大模型推理定位的公开产品，N300 是更晚的国产供应链/XCORE 1.5 方向。N260 与 N300 的量产先后不能由当前目录推断。
- C500X 是光互连产品形态，不应简单写成“C600 的上一代芯片”；它在公开资料中更像 C500 家族的板卡/互连变体。

## 6. Search / Reduce / Top-k / Address / Route / Gather / KV 与跨卡关系

这一节严格区分“公开证据”和“基于 GPU/互连常识的分析”。在已核验的官网产品页、开发者目录和招股书中，公开确认最具体的是 AllReduce、AllToAll、缓存/内存体系、MetaXLink 端口转发和多卡拓扑；没有看到沐曦公开宣称某一型号内置独立 Search、Top-k、KV Cache、Route 或 Gather 专用硬件。

| 操作/概念 | 一手资料确认情况 | 可以做的保守分析 |
|---|---|---|
| Reduce / AllReduce | 招股书明确写 MetaXLink 为千亿参数模型常用的 AllReduce、AllToAll 提供单机更优拓扑和低时延支持 | 这是跨卡集合通信/同步关系的公开证据；不等同于每个 Reduce 都由专用硬件单元完成 |
| AllToAll / Route | 招股书明确出现 AllToAll；“Route”作为 MoE 路由计算的专用硬件没有被确认 | 路由索引、Token 分发和跨卡交换可利用 GPU kernel、DMA、通信库和 MetaXLink，但具体实现未公开 |
| Search | 未确认产品级 Search 单元或搜索引擎 | 可由标量/矢量/张量 kernel、缓存和 HBM 共同完成；这是架构分析，不是 MetaX 产品事实 |
| Top-k | 未确认专用 Top-k 单元、排序网络或硬件指令 | 常见实现会读取分数、局部归约/排序、再做索引选择；是否在 MXMACA 算子库中有特定优化，需要具体版本文档或 benchmark |
| Address | 招股书典型结构出现控制单元、缓存、HBM 控制器、DMA；未公开地址生成专用单元的产品级说明 | Address generation、页表/IOMMU、虚拟化和 DMA 是数据访问路径的一部分，但不能推断具体电路组织 |
| Gather | 未确认 Gather 专用硬件；通用 GPU 的内存访问、DMA 和 kernel 能承担 Gather | 数据路径通常是索引生成 → 地址计算 → HBM/L2 读取 → 计算/通信；具体是否融合由软件栈决定 |
| KV Cache | 未确认专用 KV Cache 硬件、KV offload 或 HBM 池化产品 | LLM 推理的 KV 通常驻留在显存/缓存层级，卡间扩展受显存容量、带宽、并行切分和互连影响；不能把“支持大模型”写成“有 KV 专用加速器” |
| MetaXLink | 招股书确认低时延高带宽、多种 2–64 卡拓扑、端口直接转发；C550/C588 页面给出 8 卡 896GB/s，C600 页面给出最高 128 卡超节点 | MetaXLink 是跨卡数据传输与集合通信的关键通道；跨卡通信效率会反过来影响 Reduce、AllToAll、MoE Route 和分布式 KV 的有效性能 |

招股书还披露沐曦拥有多级缓存结构、缓存组网和可自适应多级缓存控制策略。这可以支持“缓存/内存访问是 GPU 设计重点”的判断，但不能从中推出独立的 Search、Top-k、Gather 或 KV 硬件模块。招股书披露的研发储备包括 HBM3/4 控制器、CXL 显存池化和新一代 MetaXLink，但这些是“技术储备/研发中期或初期”，不能倒写成已量产产品能力。

来源标题：沐曦《招股说明书》；披露日期：2025-10-24；访问日期：2026-09-01；[直接 PDF](https://static.sse.com.cn/stock/disclosure/announcement/c/202510/002078_20251024_OAW7.pdf)，印刷页 184–199、222–223。

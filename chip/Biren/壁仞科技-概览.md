# 壁仞科技 AI 芯片

壁仞以 GPGPU 为主线。芯片、壁砺/BILI 模组与板卡、服务器/超节点、BIRENSUPA 与云服务严格分层。

## 边界
- BR100/BR104 与 BR106/BR110 没有官方一一映射。
- BR166 是 BR106 双 die 封装；公司正式定义的第二代架构路线是 BR20X。

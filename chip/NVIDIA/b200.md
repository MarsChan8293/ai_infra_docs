# NVIDIA B200 Tensor Core GPU

> Blackwell 数据中心单 GPU。HGX/DGX/NVL72 聚合规格不属于本页。

## 核心规格
- 180GB HBM3e；最高 8TB/s。
- 第五代 NVLink，单 GPU 最高 1.8TB/s 双向。
- 单 GPU TDP、SM 数、L2 容量在现有页未统一确认，不从 DGX/HGX 反推。

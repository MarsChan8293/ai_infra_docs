# SambaNova — SN50 RDU

- 厂商总览：[SambaNova](./SambaNova-overview.md) · [[SambaNova-overview|图谱总览]]
- 产品层级：第五代 Reconfigurable Dataflow Unit；node、rack 与 256-RDU fabric 单列
- 研究截止日：2026-09-13
- 核验日期：2026-09-13

## 一句话结论

SN50 是 SambaNova 面向 agentic inference 的第五代 RDU，公开规格为 **TSMC 5nm、1600 TFLOPS BF16、3200 TFLOPS FP8、432MB SRAM、64GB HBM2E、最高 512GB DDR5**，采用 Reconfigurable Dataflow Architecture。其三级内存层次是理解产品的关键，不能把 SRAM/HBM/DDR5 三层容量混成一种“显存”。

## 单 RDU 公开规格

| 字段 | SN50 | 边界 |
| --- | --- | --- |
| 工艺 | TSMC 5nm | 芯片级 |
| 架构 | Reconfigurable Dataflow Architecture | 芯片级 |
| BF16 | 1600 TFLOPS | 厂商峰值 |
| FP8 | 3200 TFLOPS | 厂商峰值 |
| 片上 SRAM | 432MB | 片上内存 |
| HBM | 64GB HBM2E | 高带宽层 |
| DDR5 | 最高 512GB | 大容量层；不要写成 HBM |
| 单芯片 TDP | 公开资料未确认 | 不用 rack 功耗反推 |

官方产品页将 SN50 的内存架构明确描述为 three-tier memory：SRAM、HBM2E、DDR5。不同层服务于不同热度与容量的数据，尤其适合频繁切换模型/上下文的数据搬运场景。

## 系统层级

| 层级 | 公开配置 | 注意事项 |
| --- | --- | --- |
| Node | 8 SN50 chips per node | 节点级 |
| SambaRack SN50 | 16 SN50 chips | 机架级 |
| Scale-up | up to 256 RDUs | 多机架网络级 |

发布文章还给出 SambaRack 平均约 20kW 等系统功耗叙事。这个数字是**整 rack 口径**，不能除以 16 后当作单芯片 TDP，因为还包含网络、内存、主机/供电和系统开销。

## 生命周期

SambaNova 于 2026-02-24 发布 SN50，并宣布计划在 2026 年下半年开始向客户出货。当前官网已列出 SN50 产品规格，2026 年中也公开了运行模型的机架级演示/测试材料；但本次没有找到“已开始广泛商业出货”的明确官方公告。

因此状态写为：**已发布、产品页在售/展示阶段；2026H2 客户出货为厂商计划，实际广泛出货待进一步确认。**

## 性能口径

SambaNova 发布材料包含对 Blackwell B200 的速度、吞吐和 TCO 比较，以及 10T 参数模型、10M context 等系统能力主张。除非同时保留模型、量化、batch、context、并发、rack 数量和软件版本，否则这些结果不能简化成“SN50 比 B200 快 X 倍”。

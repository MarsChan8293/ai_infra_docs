# Moore Threads M1000 / 长江

> 面向端边的异构 SoC，集成 CPU、全功能 GPU、NPU、VPU、DPU、ISP 与 Audio DSP。

## 边界
- E300 是 MXM 模组，AIBOOK/AICUBE 是整机。
- 整机的统一内存/存储和 50TOPS 等组合口径不能拆给单独 NPU 或 GPU 单元。

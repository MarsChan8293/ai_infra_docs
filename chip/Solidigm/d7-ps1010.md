# Solidigm D7-PS1010

> 面向数据中心的 PCIe 5.0 NVMe TLC SSD，可作为 AI data / cache / checkpoint storage 的代表对象。

## 核心规格

- 容量：1.92 / 3.84 / 7.68 / 15.36 TB。
- PCIe 5.0 x4，NVMe。
- 顺序读最高 14.5 GB/s；系列最高顺序写公开值 10.5 GB/s，具体容量规格可能更低。
- 随机读最高约 3.3M IOPS。
- 5 年耐久度：1 DWPD。
- 平均 active power 最高 23 W；idle 5 W。

## 边界

- 性能数字是单盘规格/测试口径，不是 RAID 或 node aggregate。
- 15.36 TB 规格的顺序写公开 spec 可低于系列最高值，因此 workload 计算必须绑定具体容量 SKU。
- SSD endurance 与 KV / checkpoint 写放大应由 workload 写入量联合评估，不能只看容量。

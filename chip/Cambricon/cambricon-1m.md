# Cambricon / 寒武纪：Cambricon-1M

- 厂商总览：[寒武纪](./寒武纪-概览.md) · [[寒武纪-概览|图谱总览]]

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：终端智能处理器 IP
- 对象边界：本页只讨论 Cambricon-1M 系列 IP 配置，不把采用该 IP 的 SoC、自动驾驶系统、终端设备或云端加速卡当作 1M 芯片本体。

## 一句话结论

【已确认事实】寒武纪官方产品页公开 1M 为第三代终端架构，支持 FP32、FP16、INT32、INT16、INT8、INT4，并给出 1M-4K、1M-2K、1M-1K 在 1 GHz 下的理论峰值。[S1] 公开资料没有把这些 IP 配置与具体客户、流片、量产或当前供货绑定起来，商业成熟度只能写为“公开 IP 规格，客户实现未确认”。

## 架构与软件证据

- 【已确认事实】1M 页面把压缩/解压缩模块和多精度支持列为系列能力，并按 MAC 规模划分三个 IP 配置。[S1]
- 【已确认事实】官方 2021 年回顾将 1M 与 1A、1H 放在终端 IP 产品线，将思元220及云端 MLU 产品分到其他层级。[S2]
- 【已确认事实】NeuWare 官方页面宣称提供云边端一体、训推一体的软件平台。[S3] 这是平台范围说明，未给出 1M 专属编译器版本或当前算子覆盖。
- 【公开资料未确认】1M 的具体指令集编码、片上缓存/存储容量、内存控制器、客户 SDK 版本和已授权项目，公开资料未确认。

## 性能与采用证据

- 【已确认事实】上表是 1 GHz 条件下的 IP 理论峰值，不能替代终端 SoC 的实测吞吐、延迟或能效。[S1]
- 【厂商主张】自动驾驶和多路视频是官方列出的目标应用，但没有模型、分辨率、帧率、功耗、客户和部署条件，不能写成采用或性能 benchmark。[S1]
- 【独立验证】1M 的公开独立测试、授权客户清单和量产终端证据，公开资料未确认。

## 未确认项与冲突

1. 1M 页面有明确 IP 峰值，历史回顾也列其为已研发产品，但未公开客户项目和物理芯片实现；不能把 1M-4K 等 IP 配置视为寒武纪自有裸片型号。[S1][S2]
2. “第三代架构”和多精度支持是 IP 页面口径；客户实现可能增加不同内存、接口和功耗约束，公开资料未确认。
3. 当前官网导航仍列 1M，不足以判断每一款 IP 配置的销售、授权活跃度或停产状态。

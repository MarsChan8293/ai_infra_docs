# Cambricon / 寒武纪：Cambricon-1H

- 厂商总览：[寒武纪](./寒武纪-概览.md) · [[寒武纪-概览|图谱总览]]

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：终端智能处理器 IP
- 对象边界：本页只讨论 1H16、1H8、1H8mini 这组终端 IP 配置，不把终端 SoC、手机、模组或加速卡规格当作 1H 芯片规格。

## 一句话结论

【已确认事实】寒武纪当前官方产品页仍公开 Cambricon-1H，并明确给出第二代架构及三个 IP 配置在 1 GHz 下的峰值算力。[S1][S2] 公开资料没有确认授权客户、流片、送样、量产或具体终端部署，因此 1H 应记录为“有公开 IP 规格的产品”，不能推导为某款已量产 SoC。

## 架构与软件证据

- 【已确认事实】1H 官方页面把产品定义为终端智能处理器 IP，并按 1H16、1H8、1H8mini 区分运算单元和峰值。[S1]
- 【已确认事实】寒武纪 NeuWare 官方页面宣称软件平台覆盖云、边、端处理器，并支持训练、推理、CNNL、CNCL 和 MagicMind 等组件。[S4] 这是平台级兼容性描述，不是 1H 每个接口已实现或仍维护的证明。
- 【公开资料未确认】未找到 1H 专属指令集版本、编译目标、算子支持表、SDK 版本和芯片物理实现数据。

## 性能与采用证据

- 【厂商主张】“能效比有着数倍提升”是产品页相对上一代的定性宣传，页面没有给出测试模型、精度、功耗边界或基线，不能作为可复现能效结论。[S1]
- 【已确认事实】可复核的数值仅是 1 GHz 条件下的 IP 理论峰值，见上表。[S1]
- 【独立验证】1H 的公开独立测试和带完整条件的客户采用数据，公开资料未确认。

## 未确认项与冲突

1. 1H 页面公开了 IP 配置，2021 年回顾把它列入已研发终端产品，但两类材料都没有授权客户、流片、量产或出货信息；“公开产品页”不能升级为“已量产 SoC”。[S1][S3]
2. 1 GHz 是官方峰值规格的条件，不是所有客户实现的实际频率；不得将 TOPS 直接当成手机端到端吞吐。
3. 当前官网导航列出 1H，不能据此确定每个 1H 配置的销售、维护或停产状态。[S2]

# AMD Instinct MI210 — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：离散数据中心加速器产品，以 PCIe Add-in Card 形态交付
- 厂商与命名边界：本页把 MI210 的 GPU SKU、PCIe 卡和系统接受指南分开；裸 die 的独立规格未被 AMD 单独公开。
- 厂商总览：[AMD / 超威半导体](./AMD-overview.md) · [[AMD-overview|图谱总览]]

## 一句话结论

MI210 是 CDNA2、6 nm 的 PCIe 加速器，AMD 产品页给出 104 CU、64 GB HBM2e 和 1.6 TB/s；接受指南补充 300 W TDP。它与 MI250/MI250X 的 OAM 产品不是同一板卡形态。[S1][S3]

## 对象边界

- **本页对象**：MI210 离散 GPU 加速器 SKU。
- **芯片与封装**：产品资料公开的是 SKU/卡级可用规格，未单独披露裸 GPU die 的面积、封装内部 die 数和 die 功耗。
- **板卡**：MI210 是 full-height/full-length、双槽、被动散热 PCIe 卡；PCIe、Infinity Fabric Link 和 TDP 属于产品/平台层级。[S1][S3]
- **云与系统**：AMD 技术资料中的 Accelerator Cloud 是私有试用/验证环境，不能直接等同公有云实例 GA。[S4]

## 架构与软件证据

AMD 产品页把 MI210 归入 CDNA2，并列出 ROCm、Infinity Fabric、RAS 和 page retirement 等支持能力。[S1] 接受指南将设备标为 gfx90a，并描述双卡/四卡 hives 及 PCIe 连接；这属于主机平台拓扑，不应转写成 MI210 裸芯片互连数量。[S3] AMD 技术资料还把 ROCm 5、P2P 和 HPC/AI 工作负载作为软件使用路径。[S4]

## 性能或采用证据

产品页峰值数字是理论值。AMD 的 MI210 技术资料包含与其他产品的内部计算和私有云测试说明，但不是独立、公开、可复现的工作负载 benchmark；本文不把其比较数字升级为独立验证。[S4]

# AMD Instinct MI430X — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：面向主权 AI/HPC 的未来数据中心 GPU 产品/路线图 SKU
- 厂商与命名边界：AMD 当前产品页公开的是 MI430X 的“up to”能力和 2027 可用性；Discovery、Alice Recoque、Herder 等是系统名称，不能当作 MI430X 芯片规格。
- 厂商总览：[AMD / 超威半导体](./AMD-overview.md) · [[AMD-overview|图谱总览]]

## 一句话结论

MI430X 是 AMD 规划中的 CDNA5/MI400 家族 GPU，当前产品页只确认最高 288 TFLOPs FP64、9.2 PFLOPs FP4、432 GB HBM4、23.3 TB/s 和最高 256 WGP，并明确预期 2027 年可用；AMD 对这些数字的脚注是 2026 年工程预测，不能当作已量产芯片实测。[S1][S4]

## 对象边界

- **本页对象**：MI430X GPU 产品/路线图 SKU。
- **芯片规格**：公开页没有完整的 die、封装、功耗、互连、晶体管数或板卡规格；本页只保留当前官方页明确写出的上限值。
- **系统**：Discovery、Alice Recoque、Herder 以及主权 AI/HPC 系统是预期系统集成，属于系统/部署层。[S1]
- **比较口径**：AMD 对 Vera Rubin 的比较是 Performance Labs 工程预测；不写成独立测试或已交付产品能力。[S1][S2]

## 架构与软件证据

AMD CDNA 路线图把 MI430X 放在 CDNA5/MI400 方向，并明确 MI430 计划于 2027 年发布，未来产品可能具有不同 CDNA5 特征。[S4] MI430X 产品页以 ROCm 和主权 AI/HPC 软件栈定位产品，但未公开 MI430X 专属 ISA、XCD 数或互连实现。[S1] 因此不从 MI455X 的已公开架构细节推导 MI430X。

## 性能或采用证据

MI430X 页面脚注说明主要数字是 AMD Performance Labs 于 2026 年 7 月的工程预测，比较结果以预测值或公开值为基础，且可能变化。[S1] HPC 预览文章也使用 projected 性能表述。[S2] 本页没有独立 benchmark、量产样片或客户实测；系统名称和预期部署不构成芯片采用证明。

# AMD Instinct MI440X — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：面向企业 AI 的已宣布 GPU 产品/平台方向
- 厂商与命名边界：AMD 官方 CES 材料介绍 MI440X GPU 和紧凑型八 GPU enterprise form factor；八 GPU、Venice CPU 和 drop-in ready 是平台/系统层，不能写成单颗 MI440X 芯片规格。
- 厂商总览：[AMD / 超威半导体](./AMD-overview.md) · [[AMD-overview|图谱总览]]

## 一句话结论

截至核验日，AMD 已在 2026-01-05 CES 材料中介绍 MI440X 用于企业 AI，但没有在已核验的官方材料中公开 MI440X 专属数据表、工艺、CU、HBM、带宽、功耗、封装或 GA 日期；因此本页只记录公告和八 GPU 平台边界，不填猜测数字。[S1][S2][S3]

## 对象边界

- **本页对象**：AMD 宣布的 MI440X GPU 产品名称。
- **GPU 与平台**：AMD CES 发布称其将用于可扩展训练、微调和推理的紧凑八 GPU form factor；这证明平台定位，不证明单颗 GPU 的八卡内存、带宽或功耗。[S1]
- **系统**：CES 分发 deck 使用 Venice + MI440X、8 GPU drop-in ready 的系统图示；Venice、服务器和八卡互连不属于芯片规格。[S2]
- **专属规格资料**：截至核验日，已核验来源中没有 MI440X 专属 product page/data sheet；MI400 家族页的组合展示不能替代 SKU 数据表。[S4]

## 架构与软件证据

CES 材料提供的是企业 AI 产品定位、八 GPU 平台形态和与 Venice CPU 的组合。[S1][S2] AMD MI400 家族页展示 MI400 portfolio，但没有为 MI440X 提供足够的 SKU 级架构数据。[S4] 因此 CDNA 代际、ROCm 专属支持、ISA、互连协议和内存实现均保留为公开资料未确认。

## 性能或采用证据

已核验的 MI440X 直接资料没有完整条件的芯片峰值或 workload benchmark。八 GPU drop-in ready 是平台定位，不能当作单颗 MI440X 的性能或客户部署；本页不添加数值性能结论。[S1][S2]

# AMD Instinct MI325X — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：离散数据中心 GPU 加速器，以 OAM 模块形态交付
- 厂商与命名边界：MI325X 是 MI300X 计算配置的 HBM3E 增容版本；OAM、1,000 W、平台 8 卡和云服务分属不同层级。
- 厂商总览：[AMD / 超威半导体](./AMD-overview.md) · [[AMD-overview|图谱总览]]

## 一句话结论

MI325X 继承 CDNA3/304 CU 计算配置，AMD 产品页和数据表确认 256 GB HBM3E、6 TB/s、1,000 W Peak 的 OAM 产品。AMD 在发布时给出 2024 年第四季度生产出货、2025 年第一季度广泛系统可用的计划，但本页不把计划写成已核验的逐 SKU 出货事实。[S1][S2][S3]

## 对象边界

- **本页对象**：MI325X 离散 GPU OAM 模块。
- **封装/模块**：304 CU、1,216 Matrix Cores、256 GB HBM3E 和 256 MB Cache 是 MI325X 产品/封装公开值。[S1][S2]
- **服务器平台**：8 个 OAM、2.048 TB 总 HBM3E、聚合 P2P 带宽来自平台页，不是单个 MI325X。[S4]
- **裸芯片**：AMD 没有单独公开 MI325X 裸 die 面积、良率和单 die 功耗。

## 架构与软件证据

MI325X 数据表把它定义为 CDNA3 OAM GPU，并给出 8 个 XCD、每个 XCD 38 CU 的封装描述。[S2] AMD 产品页列出 ROCm、Infinity Fabric、SR-IOV 和 page retirement。[S1] 平台页的 8-OAM、总 HBM3E 和 P2P 数字只用于说明服务器边界，不用于扩展单 GPU 规格。[S4]

## 性能或采用证据

AMD 2024 发布材料给出 MI325X 生产出货和广泛系统可用的时间计划，但没有为单卡提供带完整软件、批次和功耗条件的独立 workload benchmark。[S3] 本页只保留产品页理论峰值；8-OAM 平台带宽与总内存不当作单个 MI325X 性能。

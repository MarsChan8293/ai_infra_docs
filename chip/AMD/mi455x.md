# AMD Instinct MI455X

> AMD 当前公开最前沿 AI 加速器。Helios 的机架聚合数字不属于 MI455X 单卡。

## 核心规格
| 字段 | 值 |
|---|---|
| 架构 / 制程 | CDNA5；TSMC 2nm + 3nm FinFET |
| 晶体管 | 320B |
| HBM | 432 GB HBM4；23.3 TB/s |
| OCP MXFP4 | 40.3 PFLOPS |
| Scale-up / Scale-out | UALoE 3.6 TB/s；UALink 0.6 TB/s，均双向口径 |
| 单卡功耗 | 公开资料未确认 |

## 生命周期与边界
- 2026-07-23 发布；逐卡量产、累计出货和公有云 GA 未确认。
- Helios 72 GPU、31TB HBM4、2.9 EFLOPS、260TB/s 属于机架级。
- 历史材料曾出现 19.6TB/s/GPU；当前产品页与 CDNA5 资料采用 23.3TB/s。

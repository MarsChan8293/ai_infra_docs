# TokenSpeed

> 围绕 LLM token 生成性能与推理优化的跨公司开源协作项目。

## 核心能力

重点关注推理执行与性能优化路径，可作为 serving engine 与 kernel 层之间的性能研究节点。

## 边界

TokenSpeed 不是 Kubernetes 控制面，也不等价于完整的模型 serving 平台。

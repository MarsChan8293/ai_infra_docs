# 昆仑芯（Kunlunxin）公开 AI 芯片产品谱系与技术证据

> 截止日：2026-09-01（Asia/Shanghai）  
> 访问日：2026-09-01  
> 研究范围：昆仑芯公开的 AI 芯片、加速卡、模组、加速器组、服务器/超节点、软件栈、集群与服务形态。  
> 证据原则：优先使用昆仑芯官网及其官方新闻；飞桨文档、腾讯云部署文档仅用于记录生态/集成侧可复现信息，并明确标注来源身份。

## 结论先行

截至截止日，昆仑芯公开资料可以确认三代 AI 计算芯片产品路线：

1. **一代 XPU（K 系列）**：官方路线图标为 2019 年，2020 年已大规模部署；当前官网仍保留一代芯片、K100、K200 的产品页。
2. **二代 XPU-R（R 系列）**：官方路线图标为 2021 年；公司介绍明确写出 2021-08 量产、2022 年启动互联网及行业客户交付。公开产品包括二代芯片、R100、R200/R200-8F、RG800，以及由 R300 模组和 R480 基板构成的 R480-X8 加速器组。
3. **三代 XPU-P（P800）**：公司官方路线图标为 2024 年量产；2025-02 官方披露 P800 万卡集群点亮，2025-03 官方披露 P800/XPU-P 和招商银行项目，2025-04 官方正式发布以 P800 为底座的超节点产品。P800 是当前公开资料中的主力高端产品，但其完整芯片规格表尚未在昆仑芯官网产品目录公开。

昆仑芯官网当前产品目录仍主要列出一代和二代产品；这与 2025-2026 新闻中对 P800、超节点和三代产品的公开信息并不矛盾，说明“官网产品目录”和“新闻/项目交付产品”不是同一个页面集合。公开资料没有足够证据确认名为 **M100、M300** 的产品已经由昆仑芯正式发布、量产或交付；本报告不把第三方页面中的这些名称计入已确认产品。

## 1. 证据标签与产品层级

本文使用以下标签：

| 标签 | 含义 |
|---|---|
| **官方事实** | 昆仑芯官网产品页、公司介绍或新闻明确写出的内容。 |
| **厂商主张** | 昆仑芯新闻中的性能、客户规模、集群效率或“领先”等宣传/项目表述；不等同于独立基准。 |
| **生态/集成方资料** | 飞桨或腾讯云的官方文档，能证明软件或部署方如何使用，但不等同于昆仑芯芯片 datasheet。 |
| **独立测试** | 本批资料中未发现可作为 P800 完整规格依据的独立公开测试报告；涉及“实测”时保留原发布方的项目语境。 |
| **分析判断** | 根据已公开的产品层级和通信关系作出的工程解释。 |
| **公开资料未确认** | 截止日检索到的公开一手页面没有给出足够证据，不用传闻或二手规格补齐。 |

产品层级严格拆开：

`芯片（die/SoC）` → `模组（module/OAM）` → `加速卡（PCIe card）` → `基板/加速器组（UBB/OAI/OCP）` → `服务器/机柜/超节点` → `集群/云服务`。

例如，P800 是芯片型号；P800 OAM 是模组；P800 单机八卡是服务器配置；32/64 卡超节点是整机柜系统；万卡集群是集群/服务基础设施。不能将这些数字混成“单芯片规格”。

## 4. 架构、存储和互联

### 4.1 架构演进

- **XPU**：昆仑芯官方称 2017 年在 Hot Chips 发布面向通用 AI 计算的自研 XPU 架构；公司又称三代 AI 计算芯片均基于该架构持续演进。
- **XPU-R**：二代芯片和 R 系列卡使用的架构。官方强调通用性、易用性，二代芯片页面明确“通用和专用指令集融合”，支持训练、推理、虚拟化，并强调高速互联用于数据/模型并行中的数据交换。
- **XPU-P**：P800 使用的第三代架构名称。官方新闻明确其面向大模型，支持 8-bit 推理、MLA 和多专家并行，但没有公开完整微架构图、计算核心数量、片上缓存层级或每类指令吞吐表。

### 4.3 互联层级

- **卡与主机**：K100/K200 使用 PCIe Gen4 x8；R100、R200、RG800 使用 PCIe 4.0 x16（R200 页面写兼容 3.0/2.0/1.0）；P800 OAM 的 PCIe Gen5 x16 只在腾讯云部署文档中出现，昆仑芯新闻未给该数字。
- **R480-X8 内部**：官方 PDF 明确 R480 基板搭载 8 个 R300 模组，8 芯片组成 2 个通信环路，片间互联双向聚合带宽 200 GB/s；产品页同时列出 200 GB/s 片间互联。这个 200 GB/s 是八模组系统互联字段，不能解释为单芯片显存带宽。
- **P800 超节点内部**：昆仑芯官方称单柜 32/64 张卡、卡间全互联，通信带宽最高提升 8 倍；XPU Link 兼容主流 Scale-Up/OISA。未公开链路数量、每链路带宽、交换芯片拓扑、拥塞控制、收发方向定义。
- **柜间/集群**：官方称超节点柜间支持 IB/RoCE，可构建万卡以上集群；P800 OAM 新闻也称支持通过 IB 或 RoCE 构建万卡级超大规模集群。

## 5. Search / Reduce / Top-k / Address / Route / Gather / KV 关系

这是本报告刻意保守的部分：公开资料常把“模型适配”“搜索业务”“多专家并行”和“集群通信”放在同一篇新闻中，但这些词不等于芯片已经公开了对应的专用硬件单元或指令实现。

### 5.1 工程上的安全推断

可以做出的有限分析判断是：昆仑芯的公开路线从二代的通用/专用指令融合和 R480 八模组互联，演进到 P800 的 MLA、MoE、XPU Link 和超节点全互联，重点明显从单卡算力扩展到“模型并行 + 集群通信 + 软件适配”的系统能力。但这只是根据公开产品组合的架构判断，不应写成“P800 内置某个已确认的 Top-k/Route/KV 专用单元”。

## 6. 软件栈与框架生态

### 6.1 昆仑芯官方资料中出现的组件

昆仑芯官网称 SDK 覆盖从底层驱动环境到上层模型转换的全栈工具。昆仑芯与飞桨的官方文章进一步给出三层适配关系：

1. **设备管理层**：XPU runtime 接入飞桨的设备管理和内存管理。
2. **计算执行层**：昆仑芯 XDNN 算子库接入飞桨算子库；缺失算子可通过昆仑芯 SDK 的 XTDK 编程接口实现内核。
3. **分布式通信层**：昆仑芯 BKCL 集合通信库接入飞桨分布式通信模块，用于多机多卡训练。

飞桨官方 XPU 安装文档还记录了 XPU 运行环境、XCCL/XHPC 等版本检查字段，并说明 XPU 版飞桨支持训练和推理。BKCL/XCCL 的命名在不同版本/文档中出现，本文不把它们未经版本核验地合并成同一个 ABI。

### 6.2 当前部署资料中的组件

腾讯云 P800 部署文档列出以下集成方所使用的组件：

- **XRE**：XPU Runtime Environment，包含内核驱动、用户态运行库和 `xpu-smi`。
- **XDR**：可编译驱动部分，用于特殊内核版本或自定义配置。
- **XDNN**：深度学习算子库。
- **XBLAS**：基础线性代数库。
- **XTDK**：模型转换、量化和格式转换工具。
- **XCCL**：集合通信库。
- **XHPC**：高性能数学计算库。

该文档还以其部署环境记录 PyTorch（xPytorch）、vLLM、SGLang，以及 MiniMax、DeepSeek、Qwen 等模型族。它证明这些软件组合存在公开部署路径，但版本、可用算子、性能和授权范围仍需以具体发行包为准。

### 6.3 框架兼容证据

- 飞桨官方硬件支持表把昆仑芯 XPU 列为 AI 加速芯片，并列出 R200、R300 等型号；文档说明 XPU 可用于训练和推理。
- 昆仑芯官方 2022 新闻称二代芯片/卡与飞桨完成 III 级兼容测试，覆盖 51 个模型、超过 400 个算子，涉及视觉、自然语言、语音、推荐、强化学习五类领域。
- 昆仑芯 2025 新闻称 P800 已与主流通用处理器、操作系统和 AI 框架完成端到端适配，并在 vLLM/SGLang 等路径持续做大模型适配；这属于厂商生态/适配声明，不是独立性能认证。

## 8. 产品状态判定

### 主力/最新

- **主力高端：P800/XPU-P 及 P800 OAM/超节点**。依据是官方三代量产路线、万卡集群点亮、招商银行项目、64 卡超节点展示、2025-04 超节点正式发布，以及 2026 年仍持续作为模型适配底座。
- **主力成熟产品：二代 XPU-R 的 R200/RG800/R480-X8**。依据是官网完整产品页、二代量产和客户交付记录，以及飞桨生态和产业方案。
- **边缘主力：R100、K100**。官方定位分别对应二代边缘卡和一代边缘卡；但公开资料没有截至日销量排名，不能用“主力”表示市场份额。

### 关键上一代

- **一代 XPU + K200/K100**：是昆仑芯进入大规模业务部署的成熟产品线，官网写明搜索引擎、小度等业务部署数万片。
- **二代 XPU-R + R200/R300/R480-X8/RG800**：连接传统数据中心训练/推理与大模型前的多卡系统，R480-X8 是公开资料中最清楚的二代多模组互联产品。

### 未确认/不纳入已发布产品表

- **M100、M300**：截至 2026-09-01，昆仑芯官网产品目录、公司路线图和本批官方新闻未确认这些型号；仅凭第三方页面或传闻不足以认定为正式产品。
- **下一代 2026-2027 产品**：官方只给出时间窗口和“多元化满足客户差异化需求”，型号、架构、规格和状态均未确认。

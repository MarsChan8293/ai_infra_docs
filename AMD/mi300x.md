# AMD Instinct MI300X — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：离散数据中心 GPU 加速器，以 OAM 模块形态交付
- 厂商与命名边界：本页的 HBM、功耗、Infinity Fabric 和 PCIe 数字是 MI300X OAM 产品/封装口径；8-OAM UBB 平台、云实例和模型服务采用单独标注。
- 综合报告导航：[AMD Instinct 综合报告](./05-amd-instinct.md)

## 一句话结论

MI300X 是 CDNA3 离散 OAM 加速器，AMD 产品页和数据表确认 304 CU、192 GB HBM3、5.3 TB/s 和 750 W；它与 MI300A 的统一 CPU+GPU APU 形态不同。MI300X 已有 Azure ND MI300X v5 云实例资料，但云可用不等于每颗芯片的出货统计。[S1][S2][S5]

## 对象边界

- **本页对象**：MI300X GPU 加速器。
- **芯片/封装**：8 个 XCD、I/O die、HBM3、256 MB Infinity Cache 和 OAM 是产品/封装公开口径；裸 die 面积、良率及单 XCD 独立 SKU 资料未披露。[S2]
- **服务器平台**：8-OAM UBB、服务器 P2P 带宽和节点总内存属于平台，不写成单个 MI300X；本页不填未在 MI300X 直接资料中核验的总量。
- **云服务**：Azure ND MI300X v5 是实例层证据，不改变 GPU 产品规格。[S6]

## 架构与软件证据

MI300X 数据表给出 8 个 XCD、每个 XCD 38 CU 的封装描述，并列出 CDNA3、Infinity Cache、Infinity Fabric、SR-IOV 和 ROCm 软件路径。[S2] AMD 产品页以 CDNA3/ROCm 为产品定位。[S1] Azure 文档只证明 MI300X 进入 ND v5 实例家族，不能从实例名称推导额外芯片硬件能力。[S5]

## 性能或采用证据

Azure ND MI300X v5 是云实例可用证据。AMD 另称 MI300X 在领先伙伴处规模部署并服务数百万用户，但该数字属于厂商采用主张。[S5][S7] 本页未纳入独立单卡 benchmark；产品页 PFLOPs 是理论峰值，系统节点的 P2P/服务吞吐不写成 MI300X 芯片实测。

# AMD Instinct MI300A — 芯片与产品证据页

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：CPU+GPU 一体化 APU 封装，面向数据中心/超级计算系统
- 厂商与命名边界：MI300A 不是可独立插入服务器的离散 GPU 卡；24 个 Zen 4 CPU 核心、CDNA3 GPU、统一 HBM3 和 APU 功耗属于同一封装/产品。系统节点和超级计算机数字另行标注。
- 综合报告导航：[AMD Instinct 综合报告](./05-amd-instinct.md)

## 一句话结论

MI300A 是 CDNA3 GPU 与 24 个 Zen 4 CPU 核心共封装的 APU，AMD 公开值为 228 CU、128 GB 统一 HBM3、5.3 TB/s；其共享地址空间和一致性是 APU 产品特征，不能把 MI300X 的离散 OAM 规格移植过来。[S1][S2]

## 对象边界

- **本页对象**：MI300A APU 产品。
- **封装**：AMD 数据表明确写 CPU 与 GPU 共享一致性 HBM3 和地址空间；GPU die、CPU die、I/O die 的裸 die 面积与单独功耗未披露。[S2][S4]
- **系统**：4-APU 连接、节点内存、El Capitan 等是平台/集群层级；不写入芯片规格表。
- **相邻 SKU**：MI300X 是离散 OAM GPU，拥有不同的 HBM 容量和接口形态。

## 架构与软件证据

MI300A 数据表明确描述 CPU、GPU 和统一 HBM3 的共享地址空间及一致性 Infinity Architecture；接受指南也把 MI300A 定义为同一封装上的 Zen 4 CPU 与 CDNA3 GPU。[S2][S4] AMD 产品页列出 CDNA、ROCm、Infinity Fabric 和 RAS 能力。[S1] 这些证据支持 APU 的架构与软件边界，不支持把 APU 的 CPU 核数、统一内存或 760 W 峰值重写成离散 GPU die 规格。

## 性能或采用证据

规格表中的 PFLOPs/TFLOPs 是理论峰值。AMD 发布材料把 El Capitan 作为 MI300A 采用系统，并给出系统级目标/结果叙述，但没有为单个 MI300A 提供具备完整条件的独立工作负载 benchmark；本文不新增单 APU 实测结论。[S3]

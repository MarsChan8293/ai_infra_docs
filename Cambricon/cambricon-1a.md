# Cambricon / 寒武纪：Cambricon-1A

- 研究截止日：2026-09-05
- 核验日期：2026-09-05
- 产品层级：终端智能处理器 IP
- 对象边界：本页只讨论可授权的 Cambricon-1A 处理器 IP，不把采用该 IP 的手机 SoC、终端设备或任何板卡当作寒武纪自有芯片产品。

## 一句话结论

【已确认事实】寒武纪官方历史材料称 1A 于 2016 年推出，面向终端并已用于“数千万智能手机”；这属于厂商历史主张，公开资料没有提供被审计的授权数量、芯片型号或当前供货状态。[S1] 2026 年官网导航已不再单列 1A，但该页面变化不能单独证明停产。[S2]

## 架构与软件证据

- 【已确认事实】官方 2018 年材料把 1A 放在“智能终端处理器 IP”产品线，并与智能云服务器芯片分列。[S1]
- 【已确认事实】官方 2021 年回顾将 1A、1H、1M 列为终端产品，将思元220、MLU100、MLU270、MLU290 等列为边缘或云端芯片/卡，说明这些名称不能跨层级互换。[S3]
- 【公开资料未确认】公开页面没有给出 1A 的指令集版本、片上存储、编译器版本、算子支持矩阵或当前 SDK 目标，不能用 NeuWare 的云边端统一描述推导 1A 的具体硬件能力。

## 性能与采用证据

- 【厂商主张】“已应用于数千万智能手机”是官方文章转述的公司历史口径；没有客户清单、芯片/手机对应关系和独立统计，因此不能当作 1A 的出货量或市场份额。[S1]
- 【独立验证】公开资料未确认。
- 【性能数据】公开资料未提供带有模型、精度、批量、延迟/吞吐和功耗条件的 1A 独立或官方可复现实测结果；不填补峰值数字。

## 未确认项与冲突

1. 2018 年历史文章称 1A 已商用并用于手机，2026 年官网导航不再列出 1A。两者分别是历史商业主张与当前导航快照，时间和证据类型不同，不能静默解释为“仍在售”或“已停产”。
2. 1A 的授权客户、被授权 SoC、流片/送样、量产、出货量、终端机型和后续路线图，公开资料未确认。
3. 未发现 1A 的裸片数据手册或独立测试；本页没有把 1H/1M 的规格借给 1A。
